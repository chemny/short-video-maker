# Responsive semantic report

Use for researched product/article/news reports with official media and authored explanatory components. Runtime template is `responsive-report` with `style.componentSystem="semantic-v1"`. This package is part of Short Video Maker, not an additional installed Skill.

Read `../../references/semantic-components.md` and `../../components/registry.json` before choosing structures. Use one palette, consistent typography and reserved platform/caption areas throughout. Actual relevant footage precedes diagrams; effects require a content reason. Never import atlas fixtures or insert demo copy.

Legacy layouts stay as compatible labels, but the structured `visualComponent` contract governs the visible component. Keep caption IDs, source intervals and factual evidence explicit. Use focus to keep content visible while emphasizing it when spoken; use reveal only for intentional sequential disclosure.

Run the normal runner, inspect measured per-scene/caption layouts and the complete video. No plan can be considered listening-approved from technical checks alone. Keep all typography responsive for 16:9, 9:16 and 3:4; do not stretch screenshots.
