# Capability-based production routing

Start by running `node scripts/inspect-capabilities.mjs` and read templates/registry.json, package rules and the actual examples. Distinguish packages, shared style routes, legacy runtime branches, semantic families and upstream recipes; none are interchangeable maturity counts.

Inputs: link/article/topic require agent research and an approved script; product/article/daily init-report produces a brief, not a finished script/video. Daily requires an explicit date. Approved scripts and imported recordings remain locked. Outputs: MP4, cover, SRT, script, source/metadata and complete preview. Editable layer workbench is not shipped.

- News/opinion: compare editorial-brief and responsive-report with supplied relevant footage. The reviewed B authored project is a visual baseline, not a universal converter. Shotcraft Brief can supply short list/statement scenes explicitly.
- Product release: keep actual official demos/screens and source intervals via responsive-report. Shotcraft UI/camera recipes complement selected shots after reviewing the real subject. Code demos must not masquerade as language practice or document analysis.
- Knowledge article: evidence diagrams/comparisons from authored facts; choose an appropriate semantic component. Short lists may use Shotcraft Brief; do not turn every paragraph into a list.
- Daily: retain editorial date, separate events and sources; limit items. Historical fixtures are labelled historical and cannot be passed as today news.

Before claiming a route is better, use the same script/audio, aspect and information payload. A single-scene probe is a typography/motion comparison, not full topical acceptance. Review the complete selected production. The rejected dense task viewer is not a baseline or a component to auto-apply.

Upgrade boundaries: preserve local TTS/ASR/audio export, evidence and aspect workflows. Imported recipes extend the visual toolbox, and can improve individual shots; they do not replace research, narration timing or semantic directing. Do not overwrite upstream skill packages or run their install/update hooks.
